SPIRAL ETHER AI — WINDOWS x64
=============================

Run:
  SpiralEtherAI.exe

This is the native Windows GPT-style Spiral Ether AI host.
The AI session/runtime is host-neutral C++ and can be embedded into EtherPlay, Hakui, EtherBeat, or another Spiral application.

WHAT YOU SEE
------------
- GPT-style conversation history
- multiline composer at the bottom
- native Win32 + Direct2D/DirectWrite UI
- Halo-3-era HUD influence + EtherPlayer-style media-console structure
- backend / GPU / model telemetry
- host-context switcher: WINDOWS / ETHERPLAY / HAKUI / ETHERBEAT

HOST CONTEXT
------------
Use the left rail to switch the active host context.
This does not replace the AI runtime. It demonstrates the same Ether AI core running as different Spiral hosts.

REAL GPT / OPENAI BACKEND
-------------------------
Spiral reads the OpenAI API key ONLY from the Windows environment.
Do not paste your key into the app conversation.

PowerShell, current window only:
  $env:OPENAI_API_KEY="YOUR_KEY_HERE"
  .\SpiralEtherAI.exe

The BACKEND chip cycles:
  AUTO -> OPENAI -> SPIRAL_LOCAL -> AUTO

AUTO behavior:
  1. Use OpenAI when OPENAI_API_KEY is present.
  2. Otherwise use a loaded native Spiral model bundle.
  3. If neither exists, say so explicitly instead of pretending random weights are intelligent.

SOVEREIGN LOCAL SPIRAL
----------------------
Drag a .bundle model file onto the app window, or type:
  /load C:\path\to\your\model.bundle

Then select SPIRAL_LOCAL from the BACKEND chip.
A trained production model bundle is not included in this package yet.

CHAT CONTROLS
-------------
- Enter: send
- Shift+Enter: newline
- Esc: clear composer
- Mouse wheel: scroll conversation
- + NEW SESSION: clear current session
- BACKEND chip: cycle AI backend
- drop a .bundle: load local Spiral model

SLASH COMMANDS STILL WORK
-------------------------
  /help
  /status
  /backend auto|openai|spiral
  /gpu
  /model
  /load <bundle-path>
  /unload
  /clear

PORTABILITY CONTRACT
--------------------
The reusable API is:
  include/spiral/ether_ai.hpp

The standalone Windows UI is only one host. EtherPlay, Hakui, and EtherBeat can instantiate the same spiral::ether_ai::Runtime without importing this Win32 UI code.

SECURITY / PRIVACY
------------------
- OPENAI_API_KEY is read from the environment and is never printed by the app.
- OpenAI calls use HTTPS through native WinHTTP.
- Local Spiral mode does not send prompts to OpenAI.

----------------
