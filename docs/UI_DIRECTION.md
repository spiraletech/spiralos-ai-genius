# Spiral Genius Native UI direction

Design target for the Windows performance-proof shell.

- Native C++ / Win32 / Direct2D / DirectWrite only.
- Halo-3-era influence: sparse military HUD hierarchy, cool cyan focus strokes, dim atmospheric field, upper-left navigation, thin technical separators.
- EtherPlayer influence: polished media-console cards, compact telemetry, large central status area, readable modern spacing.
- Original visual language only: no Halo logos, icons, copyrighted art, or copied menu assets.
- Default experience is a GUI EXE. CLI and JSON remain audit/debug tools only.
- Live benchmark results render inside the window; JSON is optional export.
